Where does the search panel live?

The current left column is a fixed 18rem file list, then the editor, then the right sidebar. How should search results coexist with the file tree?

A

Segmented toggle in the left pane (recommended)

One left column with a Files | Search switch at the top — same segmented-control pattern the right sidebar already uses (Backlinks | Mentions). Pick a mode; only one is mounted at a time. No new horizontal space.

Separate collapsible pane beside the file tree

Search gets its own column to the right of the file tree — both visible at once. Costs horizontal space; the editor narrows. Collapsible like the right sidebar.
