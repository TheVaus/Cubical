**Two real defects were found and fixed while integrating, both invisible to the type checker:**

- **The exit contract did not exist.** The frontend read `chunk.exit`; the backend's `TerminalChunk` had only `base64` and signalled exit by writing a dim `[process exited]` string into the byte stream. `onExit` could never fire. Resolved in favour of a structured exit — `TerminalChunk` gained `exit: Option<TerminalExit>` (`{code, signal}`, `skip_serializing_if` so normal chunks stay two fields on the wire), the reader thread's exit hook now `wait()`s the child through the registry before dropping it, and the inline notice string is gone. One representation, not two.
- **The plugin-disable effect double-closed.** It read `deps.tabs()` reactively, so its own `closeTab` calls retriggered it mid-loop and the second terminal was closed twice. Now `on(enabled, …)` + `untrack`. Caught by a test, not by review.

Also fixed: `--text-sm` was parsed with bare `parseFloat`, so a DS move from `14px` to `1rem` would have silently produced a **1px terminal**; the parser now rejects units xterm.js cannot use. And B4's `the_offered_flag_persists_to_the_vault_config_file` reopened the vault while the first handle still held the tantivy index lock — deterministically red, never run last session.

**Found by asking "what should I expect?" and checking rather than answering from intent:**

- `view.openTerminal` was a registered global command with **no `COMMAND_DEFAULTS` entry**, so no key could ever reach it and it never appeared in the Shortcuts panel to be rebound — the toolbar button was the only way in. Now `Mod-Shift-t`, mirroring the console's `Mod-Shift-c`.
- **`cubical` on the child `PATH` is dev-only.** `app_bin_dir()` is `current_exe().parent()`, which under `cargo tauri dev` is `target/debug/` and holds both binaries. A bundled `.app` ships only `cubical-app` in `Contents/MacOS/`, and `tauri.conf.json` declares no `externalBin`, so the spec's "quiet win" — `cubical` inside the terminal reaching the live engine — does not survive packaging. Deliberately **not** fixed here: it is release tooling (sidecar naming, target-triple suffix, a build step), not terminal work. Tracked as a GitHub issue.

`scripts/check.sh` is green apart from the pre-existing `cubical-core` watcher flake (documented in the primer; passes in isolation).

## The IPC contract (fixed — B1 and B2 both build to this)

Tauri commands:

| Command | Args | Returns |
|---|---|---|
| `terminal_open` | `vault_id`, `cols`, `rows`, `on_output: Channel<TerminalChunk>` | `{ terminal_id: String }` |
| `terminal_write` | `terminal_id`, `data: String` | `()` |
| `terminal_resize` | `terminal_id`, `cols`, `rows` | `()` |
| `terminal_busy` | `terminal_id` | `bool` |
| `terminal_close` | `terminal_id` | `()` |
| `terminal_reap_all` | — | `()` |

Output streams over a Tauri **`ipc::Channel`** handed in at open — one channel per terminal, not a global event. `TerminalChunk` is `{ base64: String, exit?: {code, signal} }`; `exit` is omitted on every chunk but the last.

`terminal_busy` compares the pty's foreground process group against the shell's own pid — that is what makes "closing a tab with a live foreground child asks first" a real check rather than a guess. `terminal_reap_all` is the belt-and-braces half of the plugin gate: the frontend closes the tabs, then asks the backend to reap anything a failed unmount left behind.

**Bytes, not strings.** A PTY emits raw bytes and a multi-byte UTF-8 character can split across chunk boundaries; decoding per-chunk corrupts it. The backend base64-encodes raw bytes, the frontend decodes to `Uint8Array` and hands that to xterm.js `write()`, which handles continuation itself. Do not `String::from_utf8_lossy` on the backend.

Exit is signalled by a final, byte-less chunk carrying the child's status. A Tauri `Channel` closing is **not** observable from JS, so the in-band marker is the only signal there is. The frontend renders it as a dim notice below the screen — not as text written into the scrollback, so there is exactly one representation of "this process ended".

## B1 — Rust PTY backend

New `crates/cubical-app/src/terminal.rs`, mirroring how `console.rs` is isolated (one `mod` + a handful of registered commands in `lib.rs`).

- `portable-pty` for the PTY pair and child spawn. Shell from `$SHELL`, fallback `/bin/sh`.
- Child env: cwd = vault root; `CUBICAL_VAULT` = vault root; app binary dir prepended to `PATH` so `cubical` resolves.
- A session registry (id → handle) in app state. Reader task per terminal pumping bytes into the channel.
- **Reaping is the risk.** `terminal_close`, vault switch, plugin disable, and app exit must all reap: `SIGTERM`, then `SIGKILL` after a grace period. A hidden `claude` mutating the vault with no visible tab is the exact failure this must not have.
- No confinement — unrestricted is the explicit ask (`foundation.md` §2.1 conditions are what replace the sandbox).

## B2 — xterm.js frontend

New `ui/src/terminal/`, mirroring `ui/src/console/`'s layout.

**Adapter boundary is mandatory** (spec §Emulator): nothing outside `ui/src/terminal/` may import xterm.js. The adapter exposes only write-bytes / resize / focus / dispose / key-handler.

**Theme shim:** xterm.js is configured from a theme object derived from DS tokens at mount and re-derived on theme change; its stylesheet is scoped to the terminal container. xterm.js contributes no colour of its own.

Add `@xterm/xterm` + `@xterm/addon-fit` to `ui/`. Wire resize → `terminal_resize` so the PTY's winsize matches, or full-screen TUIs render wrong.

## B3 — Tab kind, wiring, plugin gate

- `{kind:"terminal"}` added to the `TabView` union. **Not a singleton** — multiple terminals.
- Excluded from the keep-alive LRU (`liveFileIds`) and from session persistence. T6 already flipped `isPersistableTab` to allowlist `file`/`tag`, so persistence exclusion should be automatic — **verify, don't assume**.
- Closing a tab with a live foreground child confirms first.
- Core plugin `plugins.terminal_enabled`, **default off**, registered like `CONSOLE_PLUGIN`. Disabling closes all terminal tabs and reaps children.
- The console stays. It is removed in a **separate later commit**, once the terminal is proven.

## B4 — Agent instructions

- Generate `.cubical/agent-instructions.md` describing the `cubical` verbs and warning that raw `mv`/`rm` strand wikilinks. Cubical's own territory, written freely.
- On **first** terminal open, ask once whether to create vault-root `AGENTS.md` + `CLAUDE.md` as **one-line pointers** to it. **Default no.** Never rewritten after creation.
- This is the only vault-root write, and it is a user choice — the byte-for-byte commitment holds.

## Out of scope
